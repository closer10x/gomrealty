# Brand assets

`mark.svg` is a hand-rebuilt version of the Go-M Realty mark, used by the site
header and footer.

**To use the real asset:** replace `mark.svg` with the official file. If yours is
a PNG, save it as `mark.png` and change the two `src` values in
`src/components/SiteHeader.tsx` and `src/components/SiteFooter.tsx`.

A transparent background is required — the header sits on a cream surface, and a
white box around the mark will show.
